
# Kinetic Rail 

KineticRail is a modular, C++-based locomotive physics and simulation engine. Its primary goal is to simulate deterministic locomotive and train behavior in realistic railway test environments and generate measurable results from each virtual test. The engine evaluates static properties (mass, power, Davis equation coefficients) and dynamic states (position, velocity, acceleration) across various track conditions, using strict SI units internally.
